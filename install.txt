📚 Employee Learning Management System (LMS)
Ultimate Installation & Production Guide

Project Stack: Python/Django 🐍 | MySQL 🐬 | HTML/CSS/JS/Bootstrap 🎨 | Git/GitHub 🐙 | OS: Linux/Ubuntu 🐧
🛠️ 1. System Requirements

Before kicking off, ensure your server or development machine has these essentials loaded:

    🐍 Python 3.x

    📦 pip & Python Virtual Environment

    🌐 Django

    🐬 MySQL Server & Client

    🐙 Git

    💻 Recommended OS: Ubuntu 22.04 / 24.04 LTS (Debian-based Linux) — works smoothly on Windows & macOS too!

🐍 2. Check & Install Python

Verify your installed Python version:
Bash

python3 --version
# Example output: Python 3.12.x

If Python isn't present on your machine:
Bash

sudo apt update
sudo apt install python3 python3-pip python3-venv -y

🐬 3. Install & Configure MySQL

Get MySQL up and running:
Bash

sudo apt update
sudo apt install mysql-server mysql-client -y

# Check status, start, and enable on startup
sudo systemctl status mysql
sudo systemctl start mysql
sudo systemctl enable mysql

# Verify version
mysql --version

🗄️ 4. Create MySQL Database & User

Open the MySQL prompt:
Bash

sudo mysql

Execute these commands inside MySQL:
SQL

CREATE DATABASE lmsmgmt CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'lmsuser'@'localhost' IDENTIFIED BY 'CHANGE_THIS_PASSWORD';
GRANT ALL PRIVILEGES ON lmsmgmt.* TO 'lmsuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

    ⚠️ IMPORTANT: Replace CHANGE_THIS_PASSWORD with a strong password. Never push your database password to GitHub!

📥 5. Download / Clone the Project

Fetch the source code via Git:
Bash

git clone <YOUR-GITHUB-REPOSITORY-URL>
cd lmsmgmt

Alternatively, if using a ZIP file:
Bash

unzip lmsmgmt.zip
cd lmsmgmt

🛡️ 6. Create & Activate Python Virtual Environment

Isolate your project dependencies:
Bash

python3 -m venv venv
source venv/bin/activate

Your terminal prompt should now look like this:
Bash

(venv) user@server:~/lmsmgmt$

    💡 Tip: Always activate your virtual environment before executing any Django commands.

📦 7. Upgrade Pip

Make sure your package manager is completely up to date:
Bash

python -m pip install --upgrade pip

📥 8. Install Python Dependencies

Install packages listed in the requirements file:
Bash

pip install -r requirements.txt

If starting fresh without a requirements.txt:
Bash

pip install django mysqlclient user-agents python-dotenv

Verify Django installation:
Bash

python -m django --version

⚙️ 9. Configure the Database

Open your Django settings file (project/settings.py) and plug in your database configurations:
Python

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'lmsmgmt',
        'USER': 'lmsuser',
        'PASSWORD': 'CHANGE_THIS_PASSWORD',
        'HOST': '127.0.0.1',
        'PORT': '3306',
    }
}

🔒 10. Environment Variables (.env)

Create a .env file in your root directory to secure sensitive data:
Code snippet

SECRET_KEY=replace-with-a-secure-secret-key
DEBUG=False

DATABASE_NAME=lmsmgmt
DATABASE_USER=lmsuser
DATABASE_PASSWORD=your-database-password
DATABASE_HOST=127.0.0.1
DATABASE_PORT=3306

EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_HOST_USER=your-email@example.com
EMAIL_HOST_PASSWORD=your-email-password
EMAIL_USE_TLS=True
EMAIL_USE_SSL=False
DEFAULT_FROM_EMAIL=your-email@example.com

    🛑 NEVER upload your .env file to a public GitHub repository.

🔑 11. Django Secret Key

Production environments require a unique, high-entropy SECRET_KEY. Generate a secure key programmatically and store it strictly inside your environment configuration variables.
🔄 12. Run Database Migrations

Prepare and apply your data models:
Bash

python manage.py makemigrations
python manage.py migrate
python manage.py showmigrations

👑 13. Create Django Superuser

Set up your administrator management account:
Bash

python manage.py createsuperuser

(Follow the prompts to enter your Username, Email, and a strong Password).
📦 14. Collect Static Files

Bundle your styles, scripts, and media for production deployment:
Bash

python manage.py collectstatic

📂 15. Create Media Directories

Ensure user-uploaded files have a home:
Bash

mkdir -p media

(Verify your MEDIA_ROOT points to this directory in settings.py).
🩺 16. Test the Database Connection

Run the diagnostic check to ensure everything links properly:
Bash

python manage.py check

A healthy system returns: System check identified no issues.
🚀 17. Run Development Server

Fire up the local test server:
Bash

python manage.py runserver

🌐 Open your browser and navigate to: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
🌐 18. Run Server on Local Network

To expose the server to other devices on your local Wi-Fi/LAN:
Bash

python manage.py runserver 0.0.0.0:8000

Access via: http://SERVER-IP:8000/ (e.g., [http://192.168.1.100:8000/](http://192.168.1.100:8000/)). Do not use this method in production!
🔐 19. Admin Panel Access

Log in to your command center at:
[http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/) using your superuser credentials.
✉️ 20. Email Configuration

The LMS relies heavily on SMTP email notifications for password resets, login alerts, and course allocations. Ensure your settings.py includes active parameters:
Python

EMAIL_HOST = "smtp.example.com"
EMAIL_PORT = 587
EMAIL_USE_TLS = True
EMAIL_HOST_USER = "your-email@example.com"
EMAIL_HOST_PASSWORD = "your-password"
DEFAULT_FROM_EMAIL = "your-email@example.com"

Plaintext

🔧 39. Troubleshooting Quick Fixes

    ⚠️ "No module named django": Activate your virtual environment and run pip install -r requirements.txt.

    🐬 MySQL Connection Error: Run sudo systemctl status mysql and double-check your credentials in .env or settings.py.

    📋 Database Table Does Not Exist: Run python manage.py makemigrations followed by python manage.py migrate.

    🎨 Static Files Missing: Run python manage.py collectstatic and check STATIC_URL configurations.

    🚫 Permission Denied: Check ownership and file execution permissions on media/, static/, and project directories.
