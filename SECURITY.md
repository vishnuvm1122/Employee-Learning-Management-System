# Security Policy

## Supported Versions
We actively maintain security patches for the main branch. For critical security issues,
please follow the reporting process below.

## Reporting a Vulnerability
If you discover a vulnerability, please do NOT open a public issue. Instead:
1. Email: your-email@example.com
2. Subject: [Security] <short description>
3. Include: steps to reproduce, affected versions, potential impact, and contact info.

We will acknowledge receipt within 48 hours and coordinate a fix and disclosure timeline.

## Security Best Practices (for maintainers)
- Keep dependencies up to date (run pip-check or dependabot).
- Use environment variables for secrets (.env excluded from VCS).
- Use HTTPS for production and enable secure cookie settings.
- Rotate credentials and revoke leaked keys immediately.
